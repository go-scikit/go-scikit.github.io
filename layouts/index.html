    Get started
    
A first notebook, in four commands.

    
A notebook is a Markdown file; its go blocks are the cells. Put the notebook from the top of this page in first.md, in a module that requires the libraries it imports, and run it. It prints the quartiles of a thousand normal draws from seed 42: the draws SciPy's norm.rvs(10, 2, size=1000, random_state=np.random.default_rng(42)) makes.

    

      
shell


$ go install github.com/go-notebook/notebook/cmd/notebook@latest
$ go mod init example.com/first
$ go get github.com/go-statistics/stats github.com/go-ndarray/ndarray
$ notebook run first.md
{{ $out }}
# notebook html first.md    writes first.html
# notebook serve first.md   the same, live in the browser, editable

    

    
Run it again and every cell is kept: a cell whose code and inputs did not change is not run again, across runs. The go-notebook documentation gives the cell rules; to try the arrays and the transforms without installing anything, the go-ndarray and go-fft playgrounds run them compiled to WebAssembly in the browser, and the go-statistics and go-numerics playgrounds run whole notebooks there: edit the cells, run them, see the figures.
